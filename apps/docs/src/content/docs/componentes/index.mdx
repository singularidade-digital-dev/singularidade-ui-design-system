O Design System v2 é feito de CSS: cada componente é marcação com as classes `ss-*` do `bundle.css`, e cada prévia é essa marcação. Não há componente JavaScript para carregar. As prévias carregam o `theme.css` e o `text-styles.css` publicados em `@singularidade/tokens` e o `bundle.css` do DS v2.

Em cada prévia, os botões **Claro** e **Escuro** trocam o tema (ela começa no tema do site), e **Abrir em nova aba** mostra a prévia sozinha. Os estados (hover, foco, pressionado) aparecem lado a lado: as classes `is-hover`, `is-focus` e `is-active` simulam o ponteiro e o teclado para mostrá-los parados. As classes `ss-demo-*` existem só nas prévias; não use em produto.

## Formulário

| Componente                              | O que é                                                                    |
| --------------------------------------- | -------------------------------------------------------------------------- |
| [TextField](/componentes/text-field/)   | Campo de texto com rótulo visível; inclui CopyField e OtpField             |

| [Checkbox](/componentes/checkbox/)      | Caixa de 20px com rótulo clicável; também a linha de termos e consentimento |
| [Chips](/componentes/chips/)            | Chips de categoria, de filtro e de entrada                                 |

## Nos apps Vaadin

Os apps Vaadin Flow recebem o visual pelo tema `singularidade-base` do `vaadin-bindings`, que liga os componentes do Vaadin aos tokens. As páginas dos componentes trazem, quando há, a seção "Vaadin 25" com as propriedades que valem lá. Veja [Vaadin Flow](/devs/vaadin-flow/).

Os componentes da biblioteca `singularidade-ui-vaadin` (BoundFormPanel, ProfileEditCard, AvatarUploadField, AddressField, PhoneField, TaxIdField, EulaAcceptancePanel) ainda não estão documentados aqui.

## Storybook

O Storybook do repositório mostra os componentes do Vaadin com o tema da marca, com troca de marca e de tema. Ele ainda não tem endereço público. Para abrir:

```bash
pnpm --filter @singularidade/storybook dev   # http://localhost:6006
```

- **Foundations**: cor, tipografia, espaço, movimento, iconografia e logos.
- **Vaadin core**: campos (text-field, password, integer, number, text-area, combo-box, select, date-picker, checkbox), ações (button, menu-bar), exibição (avatar, badge, icon, progress-bar), layout (vertical e horizontal-layout, split-layout, tabs) e overlays (dialog, notification, tooltip, popover).

<Aside type="caution">
  O Storybook usa os web components do Vaadin 24 e uma cópia própria da ponte
  (`.storybook/vaadin-overrides.css`) sobre os quatro `{marca}.{tema}.css`. Ele não carrega o tema
  `singularidade-base` da 1.0.0, então pode diferir do que os apps mostram no Vaadin 25.
</Aside>
