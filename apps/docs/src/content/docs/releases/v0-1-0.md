## `@singularidade/tokens@0.1.0`

Tokens W3C DTF + Style Dictionary 4 build pipeline.

- Core: brand colors (magenta/coral/orange escalas 50-950), neutral warm-magenta undertone, feedback (success/error/warning/info)
- Semantic light + dark com hybrid color strategy
- Component tokens (button, card, input, dialog)
- Brand overlays (singularidade matriz + integras seguindo)
- Outputs: CSS multi-brand × multi-theme + JS/TS + JSON + Java

## `@singularidade/brand-assets@0.1.0`

- Logos vetoriais (Singularidade cubo + Integras X) com gradient brand
- Variantes: symbol, horizontal, vertical, monochrome
- PNG icons 16/32/180/512 por brand
- Plus Jakarta Sans + JetBrains Mono WOFF2 self-hosted
- 71 Lucide icons subset
- 10 ícones custom `ss:*` (tenant, mcp-server, tool, eula-{signed,pending}, provisioning, billing-cycle, tax-id, integration-pending, compliance)
- Build pipeline: SVG sprite, Vaadin iconset, JSON catalog
